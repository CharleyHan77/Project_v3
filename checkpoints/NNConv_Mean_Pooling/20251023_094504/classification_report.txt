指标说明:
============================================================
1. Precision (精确率): 预测为正类的样本中真正为正类的比例
   - 衡量模型预测的可靠性
   - Precision = TP / (TP + FP)

2. Recall (召回率): 真正的正类样本中被正确预测的比例
   - 衡量模型找出正类的能力
   - Recall = TP / (TP + FN)

3. F1-Score: 精确率和召回率的调和平均
   - 综合考虑精确率和召回率
   - F1 = 2 * (Precision * Recall) / (Precision + Recall)

4. Macro Average: 每个类别的指标简单算术平均
   - 平等对待每个类别，适合类别不平衡的情况

5. Weighted Average: 按每个类别样本数加权平均
   - 考虑类别不平衡，反映模型对多数类的性能
